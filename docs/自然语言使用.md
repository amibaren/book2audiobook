# 自然语言使用指南(给 LLM/agent 的指令映射)

用户用自然语言提需求,agent 按下表翻译成 `scripts/convert.py` 的参数组合。
所有常见意图已覆盖,新增意图按同样模式扩展。

## 一句话入口

```
python scripts/convert.py <书> --title <书名> --author <作者> [参数...]
```

自动判断:文字版 PDF/EPUB/TXT/MOBI 直接提取;扫描版 PDF 自动 OCR;已有工作目录则断点续传。

> ⚠️ **局部合成与打包**:只合成部分章节(`--chapters`)时不会打包(打包需全书音频齐全),
> 脚本会提示并正常退出;要试听用 `--skip-package`,正式产出需全部章节合成后再跑一次打包。

## 用户意图 → 参数映射表

| 用户说(示例) | 翻译为 | 说明 |
|---|---|---|
| "把这本书转成有声书" | `--chapters` 不传(全部) | 默认全书 1-17 章 |
| "先合成第一章试听" | `--chapters 1 --skip-package` | 只合成第 1 章,不打包 |
| "合成第三章到第五章" | `--chapters 3-5` | 范围 |
| "只要第 1、4、7 章" | `--chapters 1,4,7` | 列举 |
| "只要正文,不要注释/参考文献" | `--chapters 1-15` | 手动排除 16 注释、17 参考文献 |
| "全书加附录" | `--chapters 1-15` | 同上 |
| "用温柔淑女的声音" | `--voice 温柔淑女` | 默认音色 |
| "换个男声" | `--voice 男声` | 反卷青年 2.0 |
| "用 Vivi 的声音" | `--voice Vivi` | 音色别名见下表 |
| "重新合成(覆盖已有)" | `--force` | 默认跳过已生成块 |
| "只要音频文件,不用打包" | `--skip-package` | 调试/试听用 |
| "输出到别的目录" | `--out xxx` | 默认 `output` |

## 典型完整示例(agent 直接执行)

```powershell
# 用户:"全书转成有声书,用温柔淑女"
python scripts/convert.py 书.pdf --title 不平等的童年 --author "安妮特·拉鲁 著 · 张旭 译"

# 用户:"只要前 12 章正文,男声"
python scripts/convert.py 书.pdf --title 不平等的童年 --chapters 1-12 --voice 男声

# 用户:"第一章先做个试听"
python scripts/convert.py 书.pdf --title 不平等的童年 --chapters 1 --skip-package

# 用户:"接着上次继续合成(断点续传)"
python scripts/convert.py .output.work
```

## 约定与注意

- **断点续传**:`synth_tts2.py` 已生成的块自动跳过;`--force` 才重合成。
- **速度**:TTS2.0 约 4-6 秒/块,全书(29 万字)约 1.5-2 小时;seed 引擎慢 8-10 倍,非用户要求不用。
- **音色必须 uranus 2.0 系列**,mars 1.0 音色会报 resource mismatch(见 `docs/火山语音TTS接入.md`)。
- 章节范围超界时脚本会报错并提示全书范围,agent 应据此纠正后重试。
- 输入是**已有 work 目录**(含 book.json)时,直接续传合成,不再重新提取。
